# User Stories — REQ-03 v0.2

Format: `US-NN` · As a <persona>, I want <goal> so that <benefit>. → linked requirements. Personas are REQ-02 (to be validated in T-M1-003); US-13..US-25 were added in T-M1-007 so every requirement has a story.

| ID | Story | Req |
|---|---|---|
| US-01 | As Ayesha, I want to understand exactly what the app watches before I allow it, so that I can trust it. | FR-01, PR-05 |
| US-02 | As Bilal, I want to use the app with check-ins only, so that I can try it without usage access. | FR-02 |
| US-03 | As Ayesha, when I have been scrolling late at night, I want a gentle reminder with the sleep adhkar, so that I can put the phone down calmly. | FR-10, FR-14, FR-16, FR-21 |
| US-04 | As Bilal, when my usage looks fragmented and stressed, I want the app to ask how I feel before suggesting anything, so that it does not presume. | FR-14, NFR-08 |
| US-05 | As Hamza, I want each du'a with transliteration, meaning and its source, so that I learn it correctly. | FR-18, CR-01 |
| US-06 | As Rukhsana, I want Urdu and audio, so that I can follow easily. | FR-19, FR-28 |
| US-07 | As any user, I want to tell the app "not relevant", so that it learns my preferences. | FR-29, FR-16 |
| US-08 | As any user, I want to delete all my data with one action, so that I stay in control. | FR-25 |
| US-09 | As any user in distress, I want immediate access to real human help. | FR-24, SR-01 |
| US-10 | As any user, I want reminders never to interrupt Salah times or my quiet hours. | FR-21 |
| US-11 | As Bilal, I want a weekly reflection on my patterns, so that I can notice what affects my calm. | FR-23 |
| US-12 | As a researcher-consenting user, I want to choose exactly what I share for research, and know it never ends up in the app's model without my consent. | PR-03, FR-27, PR-07 |
| US-13 | As Ayesha, I want the app to record only when and how long I use kinds of apps, never what I read or type or where exactly I am, so that my privacy is safe. | FR-03, FR-04, FR-05, FR-06, FR-07, PR-01, PR-04 |
| US-14 | As Bilal, I want the app to compare my day with my own normal, not with other people, so that its suggestions fit me. | FR-08, FR-09, FR-11, FR-12 |
| US-15 | As Rukhsana, I want a check-in to take no more than three taps, so that it is never a chore. | FR-13 |
| US-16 | As Hamza, I want to browse du'a by situation, search them and save favourites without seeing the same one again and again. | FR-17, FR-20 |
| US-17 | As Hamza, I want a counter when a dhikr is repeated, so that I keep count without beads. | FR-22 |
| US-18 | As any user, I want to pause the app's sensing at any time, so that I decide when it watches. | FR-26 |
| US-19 | As Bilal, I want the app to work offline, respond instantly and not drain my battery or crash. | NFR-01, NFR-02, NFR-03, NFR-04, NFR-06, NFR-07 |
| US-20 | As Rukhsana, I want large text and screen-reader support, so that I can use the app with weak eyesight. | NFR-05 |
| US-21 | As any user, I want my stored data encrypted and kept only as long as needed. | PR-02, PR-06 |
| US-22 | As any user, I want the app to be clear that it is not a doctor, and to rely on what I tell it, not guesses, before treating something as a crisis. | SR-02, SR-03, SR-04, SR-05 |
| US-23 | As Hamza, I want every du'a to be authentic, checked by a scholar, matched to the situation it was taught for, and properly attributed. | FR-15, CR-02, CR-03, CR-04, CR-05, CR-06, CR-07 |
| US-24 | As the Project Lead, I want every library, model, dataset and content source to have a recorded, compatible licence, so that the app can be published lawfully. | NFR-09 |
| US-25 | As any user, I want to see why a du'a was suggested to me. | NFR-08 |
