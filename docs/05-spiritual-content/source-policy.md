# Source Policy — CON-01 v0.2 (for scholar approval at G1)

Task: T-M1-010 · Owner: AG-08 · Approver: **scholar reviewer (not yet confirmed, T-M0-006; plan: confirmed by 2026-11-15)**. Agents draft this policy; only the scholar can approve it (AGENTS.md §2).

## 0. Manhaj (D-010)
Every item comes from the Qur'an or Sahih Hadith, following the Ahl-e-Hadith tradition. Reference authorities named by the Project Lead are recorded in D-010; the reviewer applies the manhaj item by item.

## 1. Admissible sources
| Type | Admissible | Required citation |
|---|---|---|
| Qur'an | Uthmani text from **Tanzil** (tanzil.net), copied verbatim: CC BY 3.0, "changing it is not allowed", with the Tanzil Project named and linked (RES-03 §3.2). The reviewer confirms the text edition | Surah name + number : Ayah range |
| Hadith | Sahih al-Bukhari, Sahih Muslim; other collections (Abu Dawud, Tirmidhi, Nasa'i, Ibn Majah, Ahmad, etc.) **only** where graded sahih or hasan by a muhaddith the reviewer accepts, with the grading and grader named. **The list of accepted graders is set by the scholar reviewer** | Collection, book/chapter, hadith number (state the numbering system), grading + grader |
| Compilations | Recognised adhkar compilations (e.g. *Hisn al-Muslim*) may be used as a *finding aid* only; the citation must point to the primary source | Primary source as above |
| Translations | Licensed published translations with attribution, or translations by qualified translators approved by the reviewer. **Specific Urdu and English translations: to be chosen with the reviewer, with licences added to RES-03** | Translator/edition |
| Hadith Arabic text | **Source not chosen yet**: to be chosen with the reviewer; its licence goes into RES-03 before use | Edition |

## 2. Not admissible
Da'if or mawdu' narrations; unattributed "duas" circulated online; AI-generated text of any kind; modified wording.

## 3. Context mapping
The state→content mapping (which du'a suits worry, anger, sleep, etc.) must follow the context stated in the source (e.g. a du'a the Prophet ﷺ taught for worry and grief). Reviewers approve each mapping (CR-05). States follow the GOV-02 §1 taxonomy v1.

## 4. Presentation rules
Show Arabic first, with diacritics, in a proper Qur'anic/naskh font; the transliteration is labelled as an aid. Show the honorific ﷺ. Never truncate a verse mid-meaning. Respectful UI context (no ads adjacent to content). Show every attribution a source requires (CR-07). Context notes and titles avoid guilt or punishment framing (RES-02 implication 6).
