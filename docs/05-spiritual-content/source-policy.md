# Source Policy — CON-01 v0.1 (for scholar approval at G1)

## 1. Admissible sources
| Type | Admissible | Required citation |
|---|---|---|
| Qur'an | Uthmani text from a verified digital mushaf source with licence recorded (e.g., Tanzil — verify terms) | Surah name + number : Ayah range |
| Hadith | Sahih al-Bukhari, Sahih Muslim; other collections (Abu Dawud, Tirmidhi, Nasa'i, Ibn Majah, Ahmad, etc.) **only** where graded sahih or hasan by a recognised muhaddith, with the grading named | Collection, book/chapter, hadith number (state the numbering system), grading + grader |
| Compilations | Recognised adhkar compilations (e.g., *Hisn al-Muslim*) may be used as a *finding aid* only; the citation must point to the primary source | Primary source as above |
| Translations | Licensed published translations with attribution, or translations by qualified translators approved by the reviewer | Translator/edition |

## 2. Not admissible
Da'if or mawdu' narrations; unattributed "duas" circulated online; AI-generated text of any kind; modified wording.

## 3. Context mapping
The state→content mapping (which du'a suits worry, anger, sleep, etc.) must follow the context stated in the source (e.g., a du'a the Prophet ﷺ taught for worry and grief). Reviewers approve each mapping.

## 4. Presentation rules
Show Arabic first, with diacritics, in a proper Qur'anic/naskh font; the transliteration is labelled as an aid. Show the honorific ﷺ. Never truncate a verse mid-meaning. Respectful UI context (no ads adjacent to content).
